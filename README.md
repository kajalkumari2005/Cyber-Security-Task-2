# Cyber Security & Ethical Hacking Internship – Task 2

## Reconnaissance, Information Gathering, Network Scanning & Enumeration

### Objective
This project demonstrates basic network reconnaissance and enumeration in an authorized lab environment.

### Tools Used
- Kali Linux
- Nmap
- Wireshark
- Netcat
- Python 3
- DNS tools
- Traceroute

### Practical Work Completed
1. Host discovery using Nmap
2. Port scanning
3. Service/version detection
4. OS detection
5. DNS enumeration
6. Reverse DNS lookup
7. WHOIS lookup
8. Traceroute
9. Wireshark traffic analysis
10. Netcat connectivity and banner testing
11. Python host discovery
12. Python port scanning
13. Python banner grabbing
14. CSV report generation
15. JSON report generation
16. HTML report generation

### Python Files
- `src/host_discovery.py`
- `src/port_scanner.py`
- `src/banner_grabber.py`
- `src/csv_report.py`
- `src/json_report.py`
- `src/html_report.py`

### Reports
The generated CSV, JSON and HTML reports are stored in the `reports/` directory.

### Ethical Notice
All scanning and testing in this project was performed only on systems and services used for the authorized lab exercise.
